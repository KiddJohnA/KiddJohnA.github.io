The Whole Grid

Every piece of knowledge in the Book has an address: a Domain, a Context, and a Set, nested — the Set inside the Domain, the Domain inside the Context (N inside D inside C).

The address, two printings

The Book prints the address formula two ways, and the ruling between them is still open:

  • Address = (Domain × 1024) + (Context × 16) + Set — 16 domains × 64 context-slots × 16 sets = 16,384 points.
  • Address = (Domain × 256) + (Context × 16) + Set — 16 × 16 × 16 = 4,096 named addresses.
