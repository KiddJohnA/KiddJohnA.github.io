## What's here

- **`index.html`** — the Chron company page (GitHub Pages serves it as the site).
- **`wordmaths.py`** — the Wordmaths engine: the computational model as runnable code — 22 variables, all the operators, the grammar.
- **`wordmaths_request.py`** — the request layer: send a JSON word-map, get the figured computation back (statement, per-variable sentences, the model's readings). This is how an AI uses the model: it asks; the model answers.
- **`MODEL_REQUEST.md`** — the request spec for AIs and programs.
- **`examples/`** — worked requests (start with `music.json`).

## The products, in order

1. **The Chron Codex** — software that figures any subject all the way through the model. First product.
